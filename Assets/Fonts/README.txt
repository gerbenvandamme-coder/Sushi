Recoleta Bold is a commercial font and is not included in this project.

1. Buy or license Recoleta (Latinotype) and export a web build.
2. Save it here as:
     Recoleta-Bold.woff2   (preferred)
     Recoleta-Bold.otf     (optional fallback)
3. Reload the site. css/display.css picks the files up automatically.

Until the files exist, the big headings use Fraunces (Google Fonts), a similar soft serif.
